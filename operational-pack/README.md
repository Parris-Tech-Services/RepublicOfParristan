# Republic of Parristan — Operational Pack v1

Proclaimed 19 November 2026.

This pack adds the remaining pieces needed to run Parristan as a micronation, game world and family tradition.

## Contents

| Folder | What it covers |
|---|---|
| `symbols/` | Official flag, coat of arms, national anthem, National Day |
| `citizenship/` | Application form, citizen register, printable passport |
| `government/` | Ministries, how new ministers are appointed, first assembly agenda and minutes template |
| `economy/` | The Parri (currency), exchange rules, 1 Parri banknote design |
| `culture/` | National traditions and calendar |
| `game/` | Machine-readable lore (`lore.json`) and integration notes |
| `digital/` | Sovereign IT: checklist, UCS + Nextcloud runbooks, ParriBuntu build, QNAP backup, recovery |

## Privacy rule

Do not add personal contact details (home addresses, phone numbers, emails) to any file in this pack. Never commit `digital/nextcloud/.env`.

## Status of symbols

The flag, coat of arms and anthem in this pack are marked **Adopted pending First Assembly vote**. Once the First National Assembly ratifies them (see `government/first-assembly-agenda.md`), change the status to **Official**.
