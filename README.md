# Republic of Parristan — Public Government Gazette

**The public noticeboard and constitutional record of the Republic of Parristan, a developing micronation.**

[![Gazette](https://img.shields.io/badge/Gazette-Founding%20Edition-123149)](https://github.com/Parris-Tech-Services/RepublicOfParristan/tree/main/gazette)

> **Status — 19 November 2026:** Parristan is a genuine **micronational civic initiative** seeking to organise real members, constitutional government and peaceful external relationships. Its constitution is **proposed, not ratified**. Parristan is **not a recognised sovereign state**. This Gazette records notices by its organisers, not notices having statutory effect under Australian law.

The Gazette is a permanent, version-controlled record of **real announcements**, proposed constitutional measures, future ratifications and documented decisions. Each notice identifies its current status, publication date and source.

## Public consultation

Members of the public may suggest improvements using [repository issues](https://github.com/Parris-Tech-Services/RepublicOfParristan/issues), including the tracked constitutional consultation. **An issue comment is not a vote, and a GitHub account is not citizenship.**

Never post home addresses, IDs, birth dates, private contact details or sensitive information to GitHub issues. A private, consent-based membership process must be established before accepting applications.

An internal declaration, association, repository or domain does not on its own create legal statehood.

## Repository roles

This public repository provides **publication and consultation**. The separately maintained Enterprise Managed Users repository is an internal workspace. Neither repository contains a public register of private citizen records.
