# Roadmap — Building the Republic of Parristan

This roadmap distinguishes **administrative progress**, **civic legitimacy** and **international statehood**. Completing internal milestones does not itself establish sovereign status.

## Phase 0 — Establish the initiative

- [x] Choose the name Republic of Parristan
- [x] Create an internal GitHub organisation and repository
- [x] Publish an accurate status statement and draft founding documents
- [ ] Agree on a real-world mission, values and long-term objectives with prospective members

## Phase 1 — Constituent process

- [x] Identify five founding members; organiser confirms all agreed.
- [x] Founding assembly held at 3:30 pm AEDT, 19 November 2026; 5/5 attendees.
- [x] Notice rule reduced from 14 days to one hour by 5 YES / 0 NO / 0 ABSTAIN, as reported.
- [x] Constitution ratified unanimously, 5 YES / 0 NO / 0 ABSTAIN, reported effective 19 November 2026.
- [x] Open-source strategy adopted unanimously and Glenn appointed CDO/OSPO lead.
- [ ] Identify exact adopted constitutional text/SHA and confirm underlying meeting notice/circulation records and procedural validity.
- [ ] Preserve any reviewed or signed minute copies the founders' process calls for.
- [ ] Elect first President and record results.

[Minutes and evidence limitations](FOUNDING_ASSEMBLY_2026-11-19.md).

## Phase 2 — Functioning institutions

- [ ] Run the first democratic election
- [ ] Implement a private membership application and record system
- [ ] Publish an internal decision register and meeting minutes
- [ ] Approve financial controls and independent record reviews
- [ ] Establish internal complaints and appeals procedures

## Phase 3 — Civic and cultural identity

- [ ] Commission and adopt original flag, coat of arms and anthem
- [ ] Establish an official website with accurate and dated information
- [ ] Support voluntary public-service and educational projects
- [ ] Publish public reports on governance and participation

## Phase 4 — Physical presence and lawful territorial research

- [ ] Determine what physical headquarters or meeting space is useful
- [ ] Seek lawful owner permission and documented access
- [ ] Research land rights, tenure and legal feasibility
- [ ] Obtain qualified legal analysis before making any territorial claim

## Phase 5 — External relations and assessment

- [ ] Adopt a correspondence protocol
- [ ] Contact other micronations in good faith
- [ ] Maintain an evidence-backed external relations register
- [ ] Independently assess statehood aspirations and legal obstacles
- [ ] Update public claims only when objective evidence justifies them

## Enterprise trial technical workstream

- [ ] Create a non-privileged, repeatable GitHub Actions documentation check
- [ ] Add contribution and security reporting guidance
- [ ] Test repository rules and permission boundaries
- [ ] Review logging and audit evidence
- [ ] Export and back up governance records before Enterprise trial expiry
