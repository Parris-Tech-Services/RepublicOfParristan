## Priority 3 — build a useful digital administration

- [ ] Run a **one-workstation/VM Linux + LibreOffice** pilot and publish a reproducible setup guide.
- [ ] Establish an official document template using open formats and accessible PDF export.
- [ ] Pilot standards-based email/calendar access and role accounts; do not claim a government mail service before it works.
- [ ] Try privacy-aware file sharing (for example Nextcloud) and a low-friction meeting tool; test access removal.
- [ ] Inventory third-party dependencies and back up founding documents and Gazette content.
- [ ] Run one documented encrypted backup **and restore test**, with a second operator able to recover the data.
- [ ] Add a minimal documentation/link-check workflow that does not waste CI runs; confirm the public site actually deploys before announcing a live address.

**Evidence gate:** basic office, communications and records work end-to-end; every claimed service has a verified URL/test result. See [Open-Source Digital Government Strategy](OPEN_SOURCE_DIGITAL_GOVERNMENT.md).

## Priority 4 — first 90 days and beyond

- [ ] Choose and adopt original national symbols through an actual recorded procedure.
- [ ] Offer one modest, measurable civic or educational project for members and the public.
- [ ] Establish a lawful meeting venue or correspondence address, with the property owner's permission.
- [ ] Create a public annual-style status page showing actual participation, services, finances and decisions.
- [ ] Adopt a diplomatic correspondence process; engage other micronations truthfully without claiming official state recognition.
- [ ] Research property/territorial questions separately with appropriate legal advice; do not claim sovereignty over land without evidence.
- [ ] Review the digital pilot against cost, supportability, accessibility, security and ability to move hosts.
- [ ] Review whether a sustainable registered association, larger membership or service needs justify more complex infrastructure.

## Four separate kinds of progress

| Track | What counts as progress | What does **not** count |
| --- | --- | --- |
| Civic legitimacy | Consenting members, transparent votes, functioning internal institutions | Naming a President without a lawful election |
| Legal organisation | Accurate Australian legal structure, contracts and compliance | Declaring exemption from Australian law |
| Digital independence | Real working open-source services, tested exports/restores and support | Merely listing Linux/Nextcloud in a plan |
| International status | Independently documented external contacts; clear evidence for any claim | Calling correspondence diplomatic recognition |

**Important:** Parristan remains an aspiring micronational community, **not a recognised sovereign state**. Completing the checklist does not make it a sovereign country or establish recognised citizenship, passports, jurisdiction or diplomatic immunity.

Useful NSW references: [About incorporated associations](https://www.nsw.gov.au/business-and-economy/incorporated-associations/about-incorporated-associations), [registration requirements](https://www.service.nsw.gov.au/transaction/apply-to-register-an-incorporated-association), and [constitution requirements](https://www.nsw.gov.au/business-and-economy/incorporated-associations/starting-an-incorporated-association/an-incorporated-associations-constitution).

## Project-management rule

For each unchecked item, track **owner, target date, current status, evidence, blockers and next action**. Keep names and sensitive materials only in access-restricted systems; public GitHub issues should reference the task, not the private evidence.
