# Security and responsible reporting

For security vulnerabilities in this repository, please use [GitHub's private vulnerability reporting mechanism](https://docs.github.com/en/code-security/security-advisories/working-with-repository-security-advisories/configuring-private-vulnerability-reporting-for-a-repository) **if enabled**. Otherwise, avoid posting working exploits or secrets to public issues and seek a private contact channel provided by the repository owner.

Do not post passports, birth dates, home addresses, citizenship application records, recovery codes, private keys, tokens or credentials to this repository.

This Gazette is a public publication. All files are assumed discoverable and replicable. An individual's membership, registration or voting record should **not** be stored in Git history.
