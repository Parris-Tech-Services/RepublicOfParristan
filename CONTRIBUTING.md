# Contributing to the Republic of Parristan Gazette

This public repository invites peaceful, constructive input into the institutional design of a **developing micronation**.

## How to contribute

- [Constitution and founding assembly consultation](https://github.com/Parris-Tech-Services/RepublicOfParristan/issues/1)
- [National symbols consultation](https://github.com/Parris-Tech-Services/RepublicOfParristan/issues/2)
- [Report an error in a Gazette notice](https://github.com/Parris-Tech-Services/RepublicOfParristan/issues/new)
- Propose a wording change through a pull request against the `main` branch.

Please separate fact from aspiration; identify sources for factual claims; be respectful of differing political opinions; and disclose conflicts of interest when relevant.

## Gazette integrity

Published notices should be dated and uniquely numbered. Historical mistakes are corrected with dated errata, not by silently re-describing what occurred.

**Submitting or merging a GitHub pull request does not make a law, grant citizenship or count as a democratic vote.** Formal decisions require adopted procedures and verified records.

## Privacy

Never disclose other people's private information, identity documents, exact addresses, contacts, recovery keys or medical details in public issues or repository history. Public issues are not an intake system for citizenship.

## Design contributions

Only submit artwork, images and music that you created or are authorised to license for the project's use; identify the intended licence and attribution terms. No existing state symbols should be copied as Parristan's own official emblem.

No contribution gives its author governmental authority or office.
